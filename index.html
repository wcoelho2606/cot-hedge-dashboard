Automação GitHub Actions (já configurada neste repositório)

Este dashboard é atualizado automaticamente toda semana, de forma gratuita, via GitHub Pages + GitHub Actions, usando os arquivos já presentes no repositório cot-hedge-dashboard.

1. Script de coleta (`updater.py`)

Baixa os dados oficiais da CFTC, calcula a posição líquida (Long − Short) por moeda e grava o arquivo data.json consumido por esta página.

2. Workflow do GitHub Actions (`.github/workflows/cot_update.yml`)

Executa toda sexta-feira às 20:30 UTC (logo após a liberação do relatório COT), roda o updater.py e faz commit automático do data.json atualizado.

name: CFTC COT Data Auto-Updater

on:
  schedule:
    - cron: '30 20 * * 5'
  workflow_dispatch:

jobs:
  build-and-update:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repositório
        uses: actions/checkout@v3

      - name: Configurar Python 3.10
        uses: actions/setup-python@v4
        with:
          python-version: '3.10'

      - name: Instalar Dependências
        run: |
          python -m pip install --upgrade pip
          pip install pandas requests

      - name: Executar Script de Atualização
        run: python updater.py

      - name: Commit e Push das Alterações
        run: |
          git config --global user.name "GitHub Actions Bot"
          git config --global user.email "actions@github.com"
          git add data.json
          git status
          git diff-index --quiet HEAD || git commit -m "Auto-update: Dados COT CFTC atualizados"
          git push

Se o data.json não estiver acessível no momento do carregamento (ex.: primeiro deploy), esta página usa dados simulados como fallback para nunca ficar em branco, e mostra o selo "Dados Simulação/Fallback" no lugar de "Live Auto Sync".
